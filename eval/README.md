# Den 공개 평가 묶음(초안 · 2026년 11월 19일)

국가자격 필기 기출 192문항(기능사 · 산업기사 · 기사 각 44, 기능장 40, 소방시설관리사 20)을 같은 조건으로 두 모델에 묻고, Den 근거를 붙였을 때와 붙이지 않았을 때의 정답률을 비교한 측정 기록입니다.

## 파일
- `items.jsonl`: 문항 192개. 문항마다 시험 이름, 시행일과 회차, 문항 번호, 정답 번호, 네 구성의 답과 맞힘 여부가 있습니다.
- `results.json`: 구성별 맞힌 문항 수와 정답률. `items.jsonl` 에서 다시 셈한 결과와 같습니다.
- `scoring.md`: 문항 선정, 호출 조건, 판정 규칙, 결과와 해석의 한계.

## 다시 재는 방법
1. `items.jsonl` 의 시험 이름 · 회차 · 문항 번호로 공개된 기출 문항을 찾습니다.
2. 같은 문항을 쓰려는 모델에 Den 없이 5회, Den을 연결해 5회 묻습니다.
3. `scoring.md` 의 판정 규칙으로 채점하고 두 정답률의 차이를 비교합니다.
